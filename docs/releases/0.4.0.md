# 0.4.0 — First city district

## Changes from 0.3.0

- Add **City Prototype** to the main menu, alongside the existing RPG.
- Add a bounded city district with streets, sixteen solid buildings, a minimap, walking, running, and a drivable coupe.
- Add explicit vehicle entry, safe exit checks, acceleration, reverse, steering, braking, and collision checks.
- Add a repeatable parcel delivery with a $250 reward. City progress lasts for the session.
- Separate the city simulation from Phaser rendering and input.
- Add unit and browser tests, with a city browser job in GitHub CI.
- Fix menu resizing when the optional video is absent and remove its resize listener on shutdown.
- Allow menu startup on browsers without MP4 support.
- Record the development plan in [the city design document](../design/open-world-city.md).

## Scope

This release is the first playable foundation. Combat, police, traffic, pedestrians, interiors, city saves, touch controls, and a streaming world are future milestones. The Hotline Miami fork still needs to be identified and reviewed.
