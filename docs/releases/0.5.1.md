# 0.5.1 — Resilient audio startup

Changes since 0.5.0:

- Handle rejected audio decoding promises instead of stopping at the studio screen.
- Supply silent buffers for failed declared audio clips while preserving successful sound downloads and decodes.
- Verify normal audio-enabled startup, undecodable audio and missing downloads in Chromium and Firefox, including entering both the city and RPG scenes.
- Provide a virtual audio output in CI so Firefox can resume Web Audio after the start gesture.

This preserves the previous Neverquest work separately from the standalone Nightshift game.
